# 方向⑤ 续二：跨域分数校准（首个通过判据、但有隐忧）

## 问题

上一轮（见 `09-chunk-norm-variants.md`）否证了长度归一化与分层分块共五个变体，
卡点确诊为**跨域分数尺度不可比**：`layered_max` 让非 kb 涨（+1.28pp）却让 kb 掉（−2.50pp）——
块最大余弦 ≥ 整条余弦均值，非 kb 节点在全局排序中被系统性抬高，挤掉 kb 的位置。

本轮按两条路线各加一个变体：

1. **排序融合**：RRF(k=60) 合并 `layered_max` 与 `layered_top2` 两路排序
   （kb 侧两路同分，非 kb 侧取折中，指望抵消单一打分子的极端偏置）
2. **分数校准**：kb 用整条余弦；非 kb 按「块 max 的组内秩」取分位，
   映射到**非 kb 组自身整条余弦分的分布**后再统一排序——把块分数拉回整条余弦的同一尺度

## 方法（单变量）

同一份真库快照副本、同一题集（118 正样本）、同一候选口径
（`search_similar(top_k=30, expand_depth=0, apply_decay=False)`）、
同一 embedding 模型（`qwen3-embedding:0.6b`）、`chunk=400 / overlap=100`，6247 块。
新增两个变体与原六个变体在**同一批向量**上做纯分数变换。分组键 = 候选节点库内真实 `domain`。

## 逐题归因（为什么它还不算可上线方案）

对 `calib_max` 与 base 做逐题对比：

- **R@1：0.4915 → 0.4407（−5.08pp）**，来源是 **6 题从第 1 名掉到第 2 名**
  （真实 domain：hermes 3 / novel 2 / general 1），没有一题掉出 top-5。
- **R@5：0.7458 → 0.7542（+0.85pp）**，来源只有 **1 题**（q093：6 → 5）；
  「base 命中而 calib 丢掉」的题数 = **0**。
- **R@10：0.8136 → 0.8051（−0.85pp）**。

也就是说：**校准没有丢召回（top-5 零丢失），但把头部精度换掉了**——
非 kb 组内分数被重新铺开，个别节点被抬高，把 gold 从第 1 挤到第 2。
R@5 上那 +0.85pp 只有单题支撑，不足以抵消 R@1 的 6 题退步。

## 结论

1. **路线①（RRF 两路融合）否证**：−4.24pp，kb 保住了（0.00）但非 kb −6.41pp——
   把 `layered_top2` 的伤害一起融了进来，折中不等于取优。
2. **路线②（分位数校准）方向正确**：kb 精确不动（+0.00）、非 kb 与 hermes 双涨，
   首次同时满足「不伤 kb」与「非 kb 涨」——证明「跨域尺度不可比」这个诊断是对的，
   而且**可以用纯分数校准治好尺度问题，不必改索引**。
3. **但形式太粗，不能直接上生产**：代价是头部精度（R@1 −5.08pp）。
   与 09 对 `mean_top2` 的评价同型——方向对、形式粗。

## 下一步候选（未执行）

- **软校准**：`score = α·base + (1−α)·mapped`，扫 α（把「重排」降级为「微调」）
- **条件校准**：只对块数超阈值的节点校准——短节点 `max ≈ base`，本不需要动
- **保头校准**：校准只作用于 top-1 之外，或映射时保留 base 的头部顺序
- **分域校准**：本轮对所有非 kb 统一校准，尚未按 hermes/novel/general 分组各自校准

## 边界与已知问题

- 单轮数据未复跑。09 已验证同配置下 R@1/R@5/R@10 逐位稳定，
  本轮 R@1 的变化（6 题）远超该抖动幅度，结论不依赖复跑；但正式定论前仍应复跑一次。
- 只测了 `chunk=400 / overlap=100` 与 `cand=30`，未做粒度/候选量扫描。
- 校准的参考分布取「非 kb 组自身 base 分」，其他参考分布（全体 base、分域 base）未测。
- 全部实验跑在库副本上；真库 SHA256 跑前跑后一致（`7b157f93…`）。
