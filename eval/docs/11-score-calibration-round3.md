# 分块重打分续三：分数校准的三条细化路线（软校准 / 条件 / 保头 / 分域）

## 背景

上一轮（见 `10-chunk-calibration.md`）里 `calib_max` 是六个修正方向中第一个通过判据的变体
（kb 不动、非 kb 涨），但代价是 **R@1 −5.08pp**（6 题从第 1 名掉到第 2 名）。
本轮针对这个头部代价做四个细化，试图把「重排」降级为「微调」。

## 方法（单变量）

同一份真库快照副本、同一题集（118 正样本）、同一候选口径
（`search_similar(top_k=30, expand_depth=0, apply_decay=False)`）、
同一 embedding 模型（`qwen3-embedding:0.6b`）、`chunk=400 / overlap=100`，6247 块。
新增 7 个变体，全部建立在 `calib_max` 的「非 kb 映射分」之上，kb 侧一律用整条余弦：

| 变体 | 定义 |
|---|---|
| `calib_s80 / s60 / s40` | 软校准：`score = α·base + (1−α)·mapped`（α=1 → base，α=0 → calib_max） |
| `calib_cond2 / cond3` | 条件校准：只对块数 ≥ 2 / ≥ 3 的非 kb 节点校准，其余保持 base |
| `calib_head` | 保头校准：非 kb 组内 base 分最高者不被组内他人反超 |
| `calib_dom` | 分域校准：非 kb 内部按真实 `domain` 各自分组，映射到组内 base 分分布 |

## 逐题归因（关键，聚合数字全是小样本）

| 变体 | R@5 gain/loss | R@1 gain/loss | 掉出 top5 | 掉出 top1 | R@10 变化题数 |
|---|---|---|---|---|---|
| calib_max | 1 / 0 | 0 / 6 | 0 | 6 | 3（2 掉出） |
| calib_s80 | 0 / 0 | 0 / 0 | 0 | 0 | 0 |
| calib_s60 | 0 / 0 | 0 / 0 | 0 | 0 | 1（0 掉出） |
| calib_s40 | 1 / 0 | 0 / 2 | 0 | 2 | 2（2 掉出） |
| calib_cond2 | 0 / 0 | 0 / 4 | 0 | 4 | 0 |
| calib_cond3 | 0 / 0 | 1 / 2 | 0 | 2 | 0 |
| **calib_head** | **1 / 0** | **0 / 0** | **0** | **0** | **3（1 掉出）** |
| calib_dom | 1 / 1 | 1 / 6 | 1 | 6 | 2（2 掉出） |

- `calib_head` 的 R@1 = **58/118，与 base 持平**（保头生效，头部零损失）；
  但它全部变化只有 **1 题**：`q093`（hermes，6 → 5）——同时 `q085`（hermes）从 10 → 15
  **掉出 top10**。R@5 的 +0.85pp 与 R@10 的 −0.85pp 是一进一出，**净收益为零**。
- 软校准 α=0.8 / 0.6 时**逐位不变**：α=0.8 的 R@1/R@5/R@10/MRR 与 base 完全相同。
  说明校准量级本身就小到被 base 吸收，只有压到 α=0.4 才显形——而显形的同时
  2 题 R@1 损失 + 2 题掉出 top10 一起回来了。
- 条件校准（只动被切分节点）把 R@5 增益直接**归零**：说明上一轮那 1 题增益并不来自
  「被切成长块的节点」，与 `calib_max` 的设计假设并不吻合。
- 分域校准最差（R@1 −4.24pp、9 题变化、1 题掉出 top5）：组切小后秩映射更不稳。

## 结论

1. **四个细化都没有实质增益**：最好的是 `calib_head`——头部零损失（R@1 持平）但
   净收益为零（+1 题 R@5 / −1 题 R@10）。判据虽通过，量级与噪声同阶。
2. **收益与代价同源，无法分离**：`calib_max` 系列的收益（q093）与损失
   （6 题 #1→#2、q085 掉出 top10）都来自同一机制——**非 kb 组内节点互挤**。
   把头部损失压掉（保头 / 软校准）的同时，那 1 题收益也一并消失。
3. **检索期分数校准路线判定为已到边际**：三轮共 15 个变体（09/10/11），
   全部增益 ≤1 题量级（0.85pp）。停止在这一层继续加变体。
4. **复现性确认**：base 与 `calib_max` 的 R@1/R@5/R@10 与上一轮**逐位一致**
   （0.4915 / 0.7458 / 0.8136 与 0.4407 / 0.7542 / 0.8051），跨轮复现成立。
